# FNP Sales Analysis

This project focuses on analyzing **FNP (Ferns N Petals) sales data** to understand sales performance, customer purchasing patterns, product demand, and revenue trends.

### 🎯 Project Objectives

* Analyze overall sales and revenue performance
* Identify top-performing products and categories
* Understand customer purchasing behavior
* Analyze sales trends across different time periods
* Compare sales performance across locations
* Identify key business insights from the data
* Build an interactive dashboard for data-driven decision-making

### 🛠️ Tools & Technologies

* **Microsoft Excel** — Data cleaning, analysis, pivot tables, and reporting
* **Data Analysis** — KPI analysis, trend analysis, and business insights

### 📊 Key Analysis

The project analyzes important business metrics such as **total revenue, total orders, average order value, product performance, category performance, customer behavior, and sales trends**.

### 💡 Key Outcome

The analysis transforms raw sales data into meaningful business insights using interactive visualizations and KPIs, helping identify sales patterns, high-performing products, and potential areas for business improvement.

**Skills Demonstrated:** Data Cleaning • Data Analysis • Excel • Power BI • Data Visualization • KPI Analysis • Business Intelligence
